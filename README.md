# Programming Language Checklists

This repository contains structured checklists for learning Go (Golang) and Rust.

## Purpose

The goal of this repository is to:

* Provide a clear learning path
* Help track progress
* Focus on practical, real-world skills

## Contents

* Go checklist (fundamentals to advanced topics)
* Rust checklist (fundamentals to advanced topics)

## How to Use

* Work through each section step by step
* Mark items as completed as you learn them
* Build small projects alongside the checklist

## Notes

These checklists cover most important topics but are not exhaustive. Additional topics can be learned as needed while building projects.
